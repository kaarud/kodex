# Notice — rapport de couverture (KODEX CNV)

`perbase_coverage_curve.R` écrit un rapport interactif `coverage_report.html`
accompagné d'un dossier `lib/` (bibliothèques JavaScript de plotly).

**Le HTML et le dossier `lib/` doivent rester dans le même dossier.** Sans
`lib/` à côté, la page s'ouvre vide.

```
<dossier de sortie>/
├── coverage_report.html
└── lib/
```

- Pour partager le rapport, copier ou zipper le dossier entier, pas le seul HTML.
- Le rapport ne s'ouvre pas directement depuis Google Drive : le télécharger
  (dossier complet) puis l'ouvrir en local dans un navigateur.
- Les versions PNG/PDF, elles, sont autonomes.
